# The behaviours table lists every test

> Below the fold, every behaviour Kane designed is listed with its result on the old app and on each round of the rewrite.

## Find the table

Open {{start_url}}. Scroll down until the heading "All 28 behaviours" is visible, and verify the table under it has a column named "Old app" and a row named "Escape discards a todo title edit".

## Open a behaviour from the table

In the "All 28 behaviours" table, click the row named "Escape discards a todo title edit", wait two seconds, scroll to the top of the page, and verify the test file heading near the top of the page reads "Escape discards a todo title edit".
