# A screenshot opens enlarged and closes again

> Every Kane screenshot can be inspected at full size.

## Enlarge and close a screenshot

Open {{start_url}}. Click the first screenshot in the "Old app" column. Verify a dialog opens showing a larger screenshot with a "Close" button, then click "Close" and verify the dialog is gone and the test file is visible again.
